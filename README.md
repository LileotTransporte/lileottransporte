# Mobile First Delight

Atue como um UI/UX Designer Sênior e Frontend Engineer especialista em aplicações React, Tailwind CSS e Web Design Mobile-First.

Preciso que você refatore, refine e modernize totalmente a interface e a estética da minha aplicação. O objetivo principal é entregar uma experiência mobile impecável, além de uma versão adaptada de alta qualidade para Desktop.

Siga rigorosamente estas diretrizes:

1. FOCO TOTAL EM MOBILE (Prioridade Máxima / Mobile-First):

   - Desenvolva e renderize o layout priorizando primariamente a experiência em celulares (telas menores que 640px).

   - Otimize o espaçamento para interação ao toque (touch targets com mínimo de 44x44px em botões e links).

   - Garanta navegação fluida: menu responsivo (estilo drawer/hamburger ou barra inferior de navegação), tipografia escalável e legível sem necessidade de zoom.

   - Forneça a adaptação fluida e perfeita desse mesmo layout para monitores maiores e telas de PC (Desktop).

2. MANTER 100% DAS INFORMAÇÕES E FUNCIONALIDADES:

   - Preserve todo o conteúdo textual, botões, seções, fluxos e recursos funcionais já existentes no código original.

   - Não remova ou omita nenhuma funcionalidade. Reorganize visualmente de forma mais moderna e intuitiva.

3. MANTER E ELEVAR A PALETA DE CORES ORIGINAL:

   - Identifique e utilize estritamente a paleta de cores original do projeto.

   - Refine a distribuição visual dessas cores aplicando princípios de Design System: sombras suaves (subtle shadows), bordas arredondadas modernas, contraste A11Y adequado para acessibilidade e hierarquia visual clara.

4. COMPATIBILIDADE COM GITHUB PAGES (Client-Side Only):

   - O projeto continuará sendo buildado como uma aplicação estática (SPA React com Vite) e hospedado no GitHub Pages.

   - Utilize apenas estilização e componentes manipulados no client-side (Tailwind CSS, Lucide Icons, Flexbox, CSS Grid) sem dependências que exijam ambiente Server-Side (SSR ou Node.js runtime no servidor).

Por favor, apresente a interface refinada com foco principal na visualização e usabilidade MOBILE.
